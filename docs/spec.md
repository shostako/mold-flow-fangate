# 形状仕様（2026-08-27 ヒアリング＋実物写真で確定）

図: `docs/draft/geometry_draft.png`（`docs/draft/geometry_draft.py` で再生成）。builder が実際に作る 4 通り（ゲート形状 × タブ有無）の厚みマップは `docs/gate_variants_thickness.png`

座標系: 製品長辺エッジ（ゲート側）を y=0、製品側を +y、ゲート側を −y。x は長辺方向、ゲート軸は長辺中央。

| 項目 | 既定値 |
|---|---|
| 外形 | 315 × 183 |
| 額縁 | 幅 15、t=1.0（外周全体） |
| 内側 | 285 × 153、t=4.0 |

## ゲート構成（2026-08-27 確定）
ゲート形状（ファン／旧ゲート）とタブの有無は独立に選ぶ（4 通り）。**スプルー軸からゲート端までは既定 40**（パラメータ `gate_len_mm`）で、
ゲート端が圧縮部の境界。タブがあればその先 10 で製品エッジ（軸から 50）、無ければ製品エッジがゲート端に来る（軸から 40）。
ゲート形状はタブの有無で変わらない。製品がゲート側に寄るだけ。

## タブ（ゲート端 → 製品エッジ、y ∈ [−10, 0]、`tab_on`）
- 金型で「タブゲートのランド」と呼んでいる部分。幅は **製品長辺幅（315）に連動**。ファンの接続幅 250 とは別物
- y ∈ [−2, 0]: 平面 t=1.0（額縁と同厚。成形後に切る）
- y ∈ [−10, −2]: 傾斜 t=1.0 → 2.0（ゲート端で 2.0）
- タブなし: この帯が消え、ゲート端（t=2.0）が額縁（t=1.0）に直接つく

## ファンゲート（sim の FilmGateConfig と同型: 半円＋台形）
- 台形: 長辺 250 幅（ゲート端）→ 短辺 = 井戸径 20（スプルー軸線）。台形長 = `gate_len_mm` = 40
- 厚み 2.0 均一（既定）。トグルで井戸側→ゲート端の直線テーパー
- 実物斜辺の切り欠きは使い回し金型の痕跡、無視

## 旧ゲート（タブゲート）
- 幅 30 の矩形、スプルー軸線 → ゲート端（長さ `gate_len_mm` = 40）。井戸 φ20 は同位置同径で、円の下半分が矩形から出る
- 厚み: 井戸円ごと t=4.0、ゲート端手前 15 mm で 4.0 → 2.0 の傾斜、ゲート端 t=2.0 でタブ（または額縁）に接続
- 井戸深さ 3 < 4.0 なので井戸はポケットにならない（コールドスラッグ φ6 は 3+5=8 のまま）

## 肉盗み（▽ フローバランサー、`balancer_on`、v0.5.0）
- sim の `balancer_*` と同型。ゲート本体の x 中央に逆三角形の薄肉部
- 底辺（幅 `balancer_w_mm`、既定 100）は **ゲート端の線に置く**（タブ／製品エッジに接する）。頂点はスプルー側、ゲート端から `balancer_h_mm`（既定 20）
- 内側の厚み `balancer_thk_mm`（既定 1.0）。ゲート本体の内側だけ削る（ゲートブロック側なので圧縮されない）。ファン／旧ゲートどちらでも可
- 制約: 底辺幅 ≤ ゲート端の幅、高さ ≤ `gate_len − well_d/2`（頂点が井戸に入らない）
- 図: `docs/balancer_thickness.png`

## 井戸・スプルー
- 井戸: φ20 × 深さ 3、中心 = スプルー軸
- コールドスラッグ: 井戸底、φ6 × 深さ 5 の円筒
- スプルーブッシュ: L=15、上（固定側）φ4 → 下（可動側）φ6。上端が射出点
- バルブゲート φ3 はホットランナー側で製品形状には含めない（流動解析にも不要。ノズル圧損に使いたくなったらスカラーパラメータで足す）

## 圧縮部とゲートブロック（sim との最大の違い）
- **圧縮部 = 製品 + タブ**（ゲート端より製品側）。タブも製品と一緒に圧縮される
- ゲート端より軸側（ファン台形／旧ゲート矩形・井戸・コールドスラッグ・スプルー）はゲートブロックで固定厚
- sim の `FilmGateConfig` は圧縮マスク＝製品プレートのみ（ゲート側は含めない）。新 builder は `compression_mask` に製品＋タブを入れる
- 注意: sim の `Geometry.display_origin_mm()` は `compression_mask` の下端を y=0 に取る。ここでは製品エッジを y=0 にしたいので、表示原点は圧縮マスクと切り離す（製品マスクを別に持つ等）

## 決定事項
- 圧縮部は製品＋タブ 10mm、残りはゲートブロック（2026-08-27）
- スプルー軸→ゲート端 40（既定）、タブありで製品エッジまで 50。以前の「ランド端起点 50／製品エッジから 60」は聞き違い（2026-08-27）
- ゲート形状（ファン／旧ゲート）× タブ有無 の 4 通りを比較できるようにする（2026-08-27）
