# 形状仕様（2026-08-27 ヒアリング＋実物写真で確定）

図: `docs/draft/geometry_draft.png`（`docs/draft/geometry_draft.py` で再生成）。builder が実際に作る厚みマップは `docs/fan_gate_thickness.png`

座標系: 製品長辺エッジ（ゲート側）を y=0、製品側を +y、ゲート側を −y。x は長辺方向、ゲート軸は長辺中央。

## 製品（全部パラメータ）
| 項目 | 既定値 |
|---|---|
| 外形 | 315 × 183 |
| 額縁 | 幅 15、t=1.0（外周全体） |
| 内側 | 285 × 153、t=4.0 |

## ランド帯（製品エッジ外側、y ∈ [−10, 0]）
- 幅は **製品長辺幅（315）に連動**。ファンの接続幅 250 とは別物
- y ∈ [−2, 0]: 平面 t=1.0（額縁と同厚。実質のゲート、成形後に切る）
- y ∈ [−10, −2]: 傾斜 t=1.0 → 2.0

## ファンゲート（sim の FilmGateConfig と同型: 半円＋台形）
- 台形: 長辺 250 幅（y=−10、ランド帯の 2.0 側に接続）→ 短辺 = 井戸径 20（y=−60）。台形長 50 は **ランド 2.0 端起点**（製品エッジからは 60）
- 厚み 2.0 均一（既定）。**トグルで sim 同様の傾斜／肉盗みプロファイル**（profile_gate の多段テーパー流用）
- 実物斜辺の切り欠きは使い回し金型の痕跡、無視

## 井戸・スプルー
- 井戸: φ20 × 深さ 3、中心 = スプルー軸
- コールドスラッグ: 井戸底、φ6 × 深さ 5 の円筒
- スプルーブッシュ: L=15、上（固定側）φ4 → 下（可動側）φ6。上端が射出点
- バルブゲート φ3 はホットランナー側で製品形状には含めない（流動解析にも不要。ノズル圧損に使いたくなったらスカラーパラメータで足す）

## 圧縮部とゲートブロック（sim との最大の違い）
- **圧縮部 = 製品 + ランド帯 10mm**（y ≥ −10）。ランド帯も製品と一緒に圧縮される
- それ以外（ファン台形・半円井戸・コールドスラッグ・スプルー）はゲートブロックで固定厚
- sim の `FilmGateConfig` は圧縮マスク＝製品プレートのみ（ゲート側は含めない）。新 builder は `compression_mask` に製品＋ランド帯を入れる
- 注意: sim の `Geometry.display_origin_mm()` は `compression_mask` の下端を y=0 に取る。ここでは製品エッジを y=0 にしたいので、表示原点は圧縮マスクと切り離す（製品マスクを別に持つ等）

## 決定事項
- 圧縮部は製品＋ランド帯 10mm、残りはゲートブロック（2026-08-27）
- スプルー軸 50mm の起点はランド 2.0 端（2026-08-27）
- GitHub リポは public（現時点で秘匿事項なし）
