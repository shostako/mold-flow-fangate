### 教訓・技術メモ

- **井戸 φ23 で `y_gate_end` がセル中心にちょうど乗る**: pad 5 + r_well 11.5 = 16.5、+40 = 56.5 が
  1 mm 格子のセル中心（半整数）と一致し、深さ dd が整数刻みになる。開区間 `(0,1)` の probe バンドが空振り。
  φ20 系のテスト（half-integer がセル中心に来ない）では顕在化しなかった。probe は `dd >= 0` の閉区間で取る
- 翼・三角形の面積検証は全辺直線なので台形則が厳密（np.trapz 不要、numpy 2 の非推奨も回避）
- ラスタライズ面積の許容誤差は周長 × dx で見積もる（翼 240·dx、三角 60·dx）
- 実 UI 確認は playwright MCP で streamlit を headless 起動 → ラジオ click → expander/alert を JS で列挙 → スクショ。
  AppTest では拾えない実行パスの確認がこれで完結する
- matplotlib の docs 図タイトルに日本語を使うと DejaVu で豆腐（既知）。docs 図は英語タイトル
